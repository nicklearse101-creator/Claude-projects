When using Blender, be sure to use the available plugins and skills: the blender-mcp plugin tools (execute_blender_code, look, get_scene_info, etc.) and the blender-* skills in ~/.claude/skills (see [[blender-skills-cc-blender-skill]]) - load the relevant skill (modeling, materials, rendering, ...) before the work.

**Why:** Nik, 2026-10-19, after my home-made mesh polish on the Nova ([[nova-gte-project]]) did too little: "when using Blender in future - be sure to use available plugins and skills".

**How to apply:** at the start of any Blender task, invoke the matching blender-* skill(s) and follow them; this is standing approval (his global rule otherwise says ask first). Pair with [[feedback-use-research-tool]].
