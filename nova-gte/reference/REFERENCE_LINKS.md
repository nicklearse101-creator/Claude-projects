# Reference links - Nova GTE (1990)

Where to get the Phase 0 reference pack. Save downloaded images into `reference/photos/` (gitignored) under a
subfolder per source, e.g. `photos/cc_1989_red/`. Our car is a **pre-facelift** GTE (see SPEC_SHEET.md).

## Already saved
- `manuals/FIA_homologation_5375_GroupA_Opel_Nova_GTE_Corsa_GS.pdf` - factory-declared dimensions, gear ratios,
  brakes, steering, engine internals, plus period photos: front/rear 3/4 (p1), engine (p11-12), running gear and
  brakes (p13), **dashboard** (p13, LHD), suspension drawing (p15), interior dimensions (p16).

  probably has the full data panel (weight, mph/1000 rpm, measured performance):

## Blueprints - no good ready-made set exists
- getoutlines.com: no Nova / Corsa A drawing in stock. Custom order "starts at $24", 3-7 business days:
  https://getoutlines.com/requests/19361/92-vauxhall-nova-drawings
- the-blueprints.com (Dr Dan Saranga drawings, max 500 px unless logged in):
  - Nova SR 1989, side view: https://the-blueprints.com/blueprints/cars/vauxhall/68498/view/vauxhall_nova_sr_1989
  - Nova 3-door GL 1989, top view: https://the-blueprints.com/blueprints/cars/vauxhall/22933/view/vauxhall_nova_3-door_gl_1989
  - Same body as the GTE, but without the GTE arches, skirts and bumpers.
- Fallback: scale the side/top drawings to the FIA wheelbase (2343) and overhangs (670 / 609), then fit the GTE
  kit from photos.
